> 项目内怎么换图标见 `资源替换指南.md`，两者配合使用。

## 一、先分清两类「图标」

这两件事需要的资源完全不同，别混：

| | 启动图标（launcher icon） | 界面图标（UI icon） |
|---|---|---|
| 用在哪 | 手机桌面、应用列表 | App 界面内部（标签栏、按钮、列表） |
| 尺寸 | 192×192 ~ 512×512，多档 | 24×24 ~ 48×48 |
| 形态 | **面性、饱满**，单色图形撑不住 | **线性或面性**，可单色可彩色 |
| 来源 | 在线生成工具 + 简单几何图形 | 图标库 |
| 本项目 | Unity `Player Settings → Icon → Adaptive` | `Assets/Resources/Icons/` |

**图标库里的图直接拿去做启动图标会显得又小又空**——它们是按 24×24 的网格画的，
放到桌面图标尺寸上笔画太细。启动图标要么用工具生成，要么自己画一个饱满的图形。

## 二、启动图标（launcher icon）

### 在线生成工具

| 工具 | 地址 | 说明 |
|---|---|---|
| **Icon Kitchen** | https://icon.kitchen | 传前景图 + 选背景色 → 导出全套尺寸 + `ic_launcher.xml`。免费，最省事，首选 |
| Android Asset Studio | https://romannurik.github.io/AndroidAssetStudio/ | 老牌工具，功能全，但已不再维护 |

### Android 自适应图标（Adaptive Icon）要点

Android 8.0+ 要求 `Foreground` + `Background` **两层**：

- **前景图四边留约 25% 安全边距**——系统会按不同厂商的遮罩（圆形 / 方形 / 水滴）裁剪，
  贴边的图形会被切掉
- 背景层给纯色或渐变即可，本项目可以直接用 `theme.json` 里的主色 `#307AE8`
- Unity 侧：`Player Settings → Icon → Adaptive`，给 1024×1024 源图，各档尺寸自动生成
- 低版本 Android 走 `Legacy Icon`，也要填

### 聚合搜索入口

**[Iconify]** — https://icon-sets.iconify.design

聚合 200+ 图标集、27 万+ 图标，一个搜索框搜遍上面所有库，再挑合适的。

- **支持按许可证筛选**：可筛「允许商用」「是否需署名」「单色/彩色」
- 每个图标都标注所属图标集和许可证
- 框架本身是 MIT

找图标先来这里，比挨个网站翻快得多。

[Iconify]: https://icon-sets.iconify.design

### ⚠️ Iconify 上的 GPL 图标集要避开

Iconify 收录的图标集**各有各的许可证**，里面有 **GPL** 和 **CC BY-SA** 的：

- **GPL** — 传染性，闭源 App 用了有合规风险
- **CC BY-SA 4.0**（如 OpenMoji）— 要求衍生作品以相同方式共享，对闭源 App 同样有风险
- **CC BY 4.0**（如 Font Awesome Free、Solar）— 可商用，但**必须署名**

筛选时勾上「允许商用」+「无需署名」，能一次性排除掉大部分麻烦。

## 四、许可证速查

| 许可 | 可商用 | 要求 | 对本项目的实际操作 |
|---|---|---|---|
| **CC0** / Unlicense | ✅ | 无 | 什么都不用做 |
| **MIT** | ✅ | 保留版权声明 | 在「关于」页放开源许可列表 |
| **ISC** | ✅ | 保留版权声明 | 同 MIT（措辞更宽松，不要求最终产品署名） |
| **Apache-2.0** | ✅ | 保留版权声明 + NOTICE | 同 MIT，多保留一份 NOTICE |
| **CC BY 4.0** | ✅ | **必须署名** | 界面上或关于页要明确标注作者 |
| **CC BY-SA 4.0** | ✅ | 署名 + 相同方式共享 | ⚠️ 传染性，闭源 App 慎用 |
| **GPL** | ✅ | 传染性 | ⚠️ 闭源 App 避开 |
| **OFL** | ✅ | 字体专用，保留版权，不得单独出售字体 | 自带字体时适用 |

**一句话**：MIT / ISC / Apache-2.0 / CC0 随便用，记得在「关于」页放个开源许可列表；
CC BY 要署名，CC BY-SA 和 GPL 避开。

> 严格说 MIT / ISC 也要求在「软件的所有副本」中保留版权声明，所以**别把 LICENSE 文件删了**——
> 把用到的图标集的 LICENSE 一起收进项目里，是最省事的合规做法。

## 六、SVG → PNG（Unity 不认 SVG）

图标库下载下来都是 SVG，Unity 的 `Resources.Load<Sprite>` 拿不到。两条路：

**方案 A：转成 PNG（推荐）**

用 `cairosvg` 批量转，一条命令搞定一个目录：

```bash
pip install cairosvg
```

```python
# batch_svg2png.py —— 把目录下所有 SVG 转成 128x128 透明底 PNG
import pathlib
import cairosvg

SRC = pathlib.Path("icons_svg")
DST = pathlib.Path("icons_png")
SIZE = 128

DST.mkdir(exist_ok=True)

for oSvg in SRC.glob("*.svg"):
    cairosvg.svg2png(
        url=str(oSvg),
        write_to=str(DST / f"{oSvg.stem}.png"),
        output_width=SIZE,
        output_height=SIZE,
    )
    print(f"{oSvg.name} -> {oSvg.stem}.png")
```

装 `cairosvg` 报错的话，退路是 ImageMagick（`magick -background none -resize 128x128 in.svg out.png`），
或 Inkscape 命令行（`inkscape --export-type=png --export-width=128 in.svg`）。

**方案 B：让 Unity 直接读 SVG**

装 `com.unity.vectorgraphics` 包。但它产出的是 `VectorImage`，不是 `Sprite`，
`AssetProvider` 拿不到——**要改代码，不划算**，本项目走方案 A。

**下载时就把颜色定好**：Iconify 支持在 URL 上指定颜色和尺寸，直接拿白色版本省得再处理：

```
https://api.iconify.design/tabler:home.svg?color=%23FFFFFF&width=128
```

## 七、本项目的落地要点

### 硬约束：界面图标必须单色

见 `资源替换指南.md`：标签栏的选中态靠**代码染色**（选中染主色、未选中染弱化色）。
彩色图标会被压成一片纯色。所以选库时挑**单色线性**的那几个（Tabler / Lucide / Iconoir）。

想保留彩色，就得额外提供 `_on` 后缀的选中态图。

### 需要的图标清单

| 用途 | 文件名 | 显示尺寸 |
|---|---|---|
| 底部标签 ×4 | `tab_record` / `tab_list` / `tab_account` / `tab_report` | 48 |
| 翻页箭头 ×2 | `chevron_left` / `chevron_right` | 40 |
| 行尾箭头 | `chevron_right` | 44 |
| 添加 | `icon_add` | 38 |
| 删除 / 编辑 | `icon_delete` / `icon_edit` | 36 |
| 分类 ×15 | `cat_*` | 48 |

分类 slug：`cat_food` 餐饮、`cat_shopping` 购物、`cat_transport` 交通、`cat_housing` 住房、
`cat_entertainment` 娱乐、`cat_medical` 医疗、`cat_education` 学习、`cat_communication` 通讯、
`cat_social` 人情、`cat_other` 其他、`cat_salary` 工资、`cat_bonus` 奖金、`cat_parttime` 兼职、
`cat_investment` 投资收益、`cat_redpacket` 红包。

**规格**：128×128 PNG、透明底、单色。

### ⚠️ 中国特有概念在英文库里找不到

`cat_redpacket`（红包）、`cat_social`（人情往来）这类概念，国外图标库里基本没有对应物。
可行的替代：

- 红包 → `gift` / `envelope` / `mail` / `cash`
- 人情 → `users` / `heart-handshake` / `gift`

**Remix Icon** 是中日韩场景覆盖相对好的一个，值得先在那儿找。
实在不行就自己画——单色线性图标在 Inkscape / Figma 里画一个不比找图慢多少。

### 换图流程（不需要改代码）

1. PNG 按上表命名，丢进 `Assets/Resources/Icons/`
2. 选中图片，`Texture Type` 保持默认的 `Sprite (2D and UI)`
3. 回 Unity 点 Play 看效果

`AssetProvider` 是全项目唯一碰 `Resources.Load` 的地方，**找不到图就返回 `null`**，
页面自动退回文字兜底——所以可以只换一部分，界面不会崩。
