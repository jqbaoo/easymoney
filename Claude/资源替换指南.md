# 资源替换指南

界面代码已经建好资源层，遵循**资源优先、代码兜底**：把文件按约定名字放进
`Assets/Resources/`，重启即生效，**一行代码都不用改**。没放文件时界面用代码画的
兜底形态，照样能跑、能看、能点。

---

## 目录约定

```
Assets/Resources/
├── Icons/          图标（PNG，透明底）
├── Sprites/        卡片 / 按钮底图（九宫格）
├── Fonts/          字体
└── theme.json      配色
```

文件名不带扩展名引用。`Resources.Load` 的路径就是相对 `Assets/Resources/` 的路径，
所以 `Assets/Resources/Icons/chevron_right.png` 在代码里叫 `chevron_right`。

**建议规格**：统一 `128×128` PNG，透明背景，单色（白色或黑色）为佳。

### 为什么建议单色

标签栏的选中态是靠**代码染色**实现的：选中染主色、未选中染弱化色。
如果图标本身就是彩色的，染色会把它压成一片纯色。

想保留彩色图标也可以，那就再提供一张选中态图（见下）。

### 选中态图标（可选）

标签栏支持 `_on` 后缀的选中态：

```
tab_list.png      未选中
tab_list_on.png   选中
```

给了 `_on` 就用 `_on`，没给就把 `tab_list.png` 染成主色。两种都能用，混着用也行。

### 分类图标

| slug | 分类 | slug | 分类 |
|---|---|---|---|
| `cat_food` | 餐饮 | `cat_salary` | 工资 |
| `cat_shopping` | 购物 | `cat_bonus` | 奖金 |
| `cat_transport` | 交通 | `cat_parttime` | 兼职 |
| `cat_housing` | 住房 | `cat_investment` | 投资收益 |
| `cat_entertainment` | 娱乐 | `cat_redpacket` | 红包 |
| `cat_medical` | 医疗 | | |
| `cat_education` | 学习 | | |
| `cat_communication` | 通讯 | | |
| `cat_social` | 人情 | | |
| `cat_other` | 其他 | | |

分类的图标名存在数据库里，所以**新增分类时不用改代码**——用户在分类管理里
填什么图标名，界面就找什么图。

这 15 张已经接进四处界面：**账单列表行行首、报表占比行行首、记账页「分类」行、
分类选择弹窗**。图标色统一取 `Theme.TEXT_WEAK`（跟副标题同色）——它是辅助信息，
不该抢金额和标题的戏。

⚠️ **没图标的分类留一个等宽空位，而不是不画那一格。** 用户自建的分类没有图标名，
若那一格干脆不建，这一行的文字会往左顶，跟上下行的左边缘参差不齐。
实现在 `UiFactory.CreateIconSlot`：无条件占一格，没图就整格透明（返回 `Image`
而不是 `RectTransform`，是为了记账页选中分类后能**就地换图**而不必换节点）。

⚠️ **别只改这个目录就以为万事大吉**：图标名是**数据**，同一份对照表还写在
`Data/DefaultCategories.cs`（新装的库走种子）和 `Data/SchemaMigrations.cs`
的 v2 迁移（老库靠它补）两处，编译器管不了。
`Defaults_IconNames_ResolveToExistingResources` 会检查每个图标名都解析得到真图，
`CategoryIconMigration_MatchesFreshInstallSeed` 会检查两条路到达同一状态——
新增或改名分类图标时，这两条测试就是安全带。

## 二、卡片 / 按钮底图

| 文件名 | 用途 | 缺失时的兜底 |
|---|---|---|
| `card.png` | 所有卡片、列表行的圆角底 | 代码程序化生成圆角矩形 |
| `button.png` | 所有按钮的底图 | 复用 `card.png`；都没有就程序化生成 |

**卡片投影是代码画的，不在底图里。** 程序化兜底走 `UiFactory.AddCardShadow`
（UGUI 的 `Shadow` 组件，向下偏移 `Theme.SHADOW_OFFSET`，颜色取 `theme.json` 的
`shadow`）。账单行、账户行、报表行、两个弹窗面板都铺了这一层。

这么做是因为**投影烘进底图会连累布局**：九宫格的 border 必须连投影一起包住，
那张图被拉伸到节点尺寸时卡片本体就比节点小一圈，行高、内边距、行间距全得跟着重量。

代价是 `Shadow` 只做偏移复制、不做模糊，**边缘是硬的**。想要柔和投影就给一张
`card.png`——`AssetProvider` 优先用图，程序化那条路自动让位。给图时 border 要把
投影一起包住，并相应把卡片节点的内边距调大。

**关键：必须切成九宫格。** 在 Unity 里选中图片 → Inspector →
`Sprite Editor` → 拖拽 Border 的四条边，然后 Apply。

- 左右 border 至少要盖住圆角半径（当前是 16pt，即 2 倍图上的 32px）
- 上下同理
- 中间留一段可拉伸的区域

没设 border 的话，图片会被整体拉伸，圆角会变形。

**建议规格**：`128×128` PNG，四周圆角。想加阴影就把阴影画在图里，
但注意九宫格的 border 要留够，别把阴影也拉伸了。

## 三、字体

放一个文件即可：

```
Assets/Resources/Fonts/main.ttf
```

放进去就自动全局生效。**注意**：字体文件较大会显著增加包体，中文全字库通常
10MB 起步，建议做子集化或者用思源黑体的精简版。

不放的话，代码按以下顺序找系统字体：

```
Microsoft YaHei → 微软雅黑 → Noto Sans CJK SC → Source Han Sans CN →
Droid Sans Fallback → PingFang SC → Heiti SC → SimHei → SimSun → Arial Unicode MS
```

最后兜底是 Unity 内置字体（不含中文，会显示方块）。Android 真机上通常能命中
`Noto Sans CJK SC` 或 `Droid Sans Fallback`，但**不能保证**，所以正式发布
建议还是自带字体。

## 四、配色

改 `Assets/Resources/theme.json`：

```json
{
  "background":  "#F2ECE2",
  "surface":     "#FFFCF6",
  "primary":     "#A9714B",
  "expense":     "#C0523C",
  "income":      "#4F8A5B",
  "textPrimary": "#2B2620",
  "textWeak":    "#8A8177",
  "divider":     "#E7DFD2",
  "barTrack":    "#E7DFD2",
  "scrim":       "#00000073",
  "shadow":      "#46311C1A"
}
```

当前是**暖色纸感**：燕麦米白的底、暖白的卡片、焦糖棕的主色，像纸质账本。

⚠️ **底色和卡片色只差十几个色阶，光靠它们分不出层次**——卡片和底之间的边界
是那层投影交代的（见下节）。所以改配色时别把 `shadow` 调没了。

| 字段 | 含义 |
|---|---|
| `background` | 页面底色 |
| `surface` | 卡片、标签栏、标题栏底色 |
| `primary` | 品牌主色（按钮、选中态、可点击文字） |
| `expense` | 支出金额颜色 |
| `income` | 收入金额颜色 |
| `textPrimary` | 主要文字 |
| `textWeak` | 次要文字、说明文字 |
| `divider` | 分割线 |
| `barTrack` | 报表条形图的轨道底色 |
| `scrim` | 遮罩（弹窗背后的灰） |
| `shadow` | 卡片投影。暖底上用纯黑会发灰，所以给的是偏棕的暖黑，靠 alpha 控制轻重 |

**格式**：`#RRGGBB` 或 `#RRGGBBAA`（后两位是透明度，`73` ≈ 45%）。

**可以只写想改的项**，没写的自动用默认值。例如只想换主色：

```json
{ "primary": "#FF6B35" }
```

写错了（格式不合法）也只是该项退回默认，不会崩。

### 深色模式

`ThemePalette.Dark()` 已经定义好了（`ThemePalette.cs`），代码层面支持运行时切换：

```csharp
Theme.Apply(ThemePalette.Dark());   // 换深色，界面自动重建
Theme.Apply(ThemePalette.Light());  // 换回来
```

目前没有接切换入口（设置页还没做）。等做设置页时，在那里调 `Theme.Apply` 即可，
界面会整体重建，**页面代码一处都不用动**。

想直接改深色配色，就改 `ThemePalette.Dark()` 里的色值。

## 换资源的标准流程

1. 图片按上表命名，丢进对应目录
2. 如果是底图，进 Sprite Editor 切九宫格 border
3. 选中图片，`Texture Type` 保持默认的 `Sprite (2D and UI)`
4. 回到 Unity，直接 Play 看效果

**不需要改代码，不需要改场景，不需要重新挂引用。**

如果是在 Play 模式下新丢的图片，静态缓存不会自动刷新，重新 Play 一次即可。

## 代码侧速查

| 想改什么 | 改哪里 |
|---|---|
| 尺寸、间距、字号 | `Theme.cs` 上半部分（都是 `const`） |
| 配色 | `Resources/theme.json` 或 `ThemePalette.cs` |
| 图标名字 | `IconNames.cs` |
| 资源路径 / 新增具名资源 | `AssetPaths.cs` |
| 加载逻辑 | `AssetProvider.cs` |
| 组件样式（按钮、卡片、滚动区长什么样） | `UiFactory.cs` |
| 圆角兜底图形的画法 | `SpriteFactory.cs` |
| 系统字体候选顺序 | `FontProvider.cs` |

**页面代码（`UI/Pages/*.cs`）里不应该出现任何写死的颜色、字号或图片路径。**
如果发现需要改页面才能换资源，那是个 bug，应该把那个东西挪进 `Theme` 或
`IconNames`。
