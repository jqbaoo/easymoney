# 账单管理系统 MVP 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 Unity 2022.3 上做出一个能在 Android 手机上日常使用的本地记账 App，覆盖账户管理、账单记录、分类管理、搜索筛选、基础报表五个模块。

**Architecture:** 三层 asmdef 分层。`EasyMoney.Core` 是零 Unity 依赖的纯 C# 领域层（模型 + 金额类型 + 报表计算），`EasyMoney.Data` 是 SQLite 持久化层（手写 SQL，仓储接口），`EasyMoney.App` 是 UGUI 界面层。所有业务逻辑住在 Core/Data，可以在 EditMode 里用真实 SQLite 内存库跑测试；UI 层只做展示与转发，不做计算。数据存 SQLite 单文件，放在 `Application.persistentDataPath`。Python 后端不在本期范围，留待「共享协作 / 多端同步」阶段。

**Tech Stack:** Unity 2022.3.53f1c1（2D 模板）/ C# / UGUI + TextMeshPro / SQLite（sqlite-net-pcl）/ Unity Test Framework (NUnit, EditMode)

**Spec:** `Claude/账单管理系统功能清单.md`

## Global Constraints

- **Unity 编辑器路径（已实测确认）**：`D:\unity\unity2022\2022.3.53f1c1\Editor\Unity.exe`。用 bash 调用时写作 `/d/unity/unity2022/2022.3.53f1c1/Editor/Unity.exe`。
- **Unity 版本**：`2022.3.53f1c1`，不要升级，不要改动 `ProjectSettings/ProjectVersion.txt`。
- **目标平台**：Android。构建产物必须是 APK，能在真机安装运行。
- **本期不做**：预算、提醒、标签、共享协作、OCR、多币种、云同步、AI 建议。这些在文末「后续路线图」里，**不要在本期顺手实现**。
- **金额一律用 `long` 存「分」**，全项目禁止用 `float`/`double` 表示金额。`decimal` 只允许出现在「用户输入解析」和「界面显示格式化」两处。
- **时间一律用 `long` 存 Unix 毫秒（UTC）**，全项目禁止把 `DateTime` 直接写进数据库或当参数传递；只在显示和「按月/按日分组」时转成本地时间。
- **命名风格（用户强制要求，务必逐条遵守）**：
  - 私有字段 `m_` 前缀 + 大驼峰：`m_Id`、`m_Items`
  - 私有方法小驼峰 + `_` 前缀：`_loadPage()`、`_refreshList()`
  - 公开方法 / 属性大驼峰：`RefreshList()`、`TotalCents`
  - 局部变量加类型前缀：`iCount`(int)、`sName`(string)、`dMap`(dict)、`tPair`(tuple)、`lItems`(list)、`oAccount`(对象)、`bFlag`(bool)、`fRate`(float)
  - 常量全大写下划线分隔：`MAX_PAGE_SIZE`、`DEFAULT_ACCOUNT_ID`
- **数据库表名一律小写单数 + 下划线列名**：`account`、`category`、`tx`。表名 `tx` 而非 `transaction`（后者是 SQL 保留字）。
- **每次提交只包含一个任务**，提交信息用中文 `feat:` / `test:` / `chore:` 前缀，例如 `feat: 添加 Money 金额值类型`。
- **Unity 项目提交必须带上 `.meta` 文件**，否则资源引用会丢失。新文件用 `git add` 时不要漏掉同名 `.meta`。
- **跑测试前必须先关掉 Unity 编辑器**。同一个项目无法同时被编辑器和命令行实例打开，会报 `Multiple Unity instances cannot open the same project`。

```bash
#!/usr/bin/env bash
# 命令行跑 EditMode 测试。用法: bash Tools/run-editmode-tests.sh
# 退出码: 0 = 全部通过; 1 = 有测试失败; 2 = 环境/编译错误
set -uo pipefail

PROJECT_PATH="E:/Projects/easymoney"
UNITY_EXE="${UNITY_EXE:-D:/unity/unity2022/2022.3.53f1c1/Editor/Unity.exe}"
RESULTS="$PROJECT_PATH/Temp/editmode-results.xml"
LOGFILE="$PROJECT_PATH/Temp/unity-test.log"

mkdir -p "$PROJECT_PATH/Temp"

if [ ! -f "$UNITY_EXE" ]; then
  echo "找不到 Unity 编辑器: $UNITY_EXE"
  echo "请设置环境变量 UNITY_EXE 指向 Unity.exe"
  exit 2
fi

rm -f "$RESULTS"

"$UNITY_EXE" \
  -batchmode \
  -nographics \
  -projectPath "$PROJECT_PATH" \
  -runTests \
  -testPlatform EditMode \
  -testResults "$RESULTS" \
  -logFile "$LOGFILE"
UNITY_EXIT=$?

if [ ! -f "$RESULTS" ]; then
  echo "=== 测试未产生结果文件，多半是编译错误。日志尾部： ==="
  tail -60 "$LOGFILE"
  exit 2
fi

grep -oE '<test-run[^>]*result="[^"]*"[^>]*passed="[0-9]+"[^>]*failed="[0-9]+"' "$RESULTS" | head -1
grep -oE 'failed="[0-9]+"' "$RESULTS" | head -1

if grep -q 'result="Failed"' "$RESULTS"; then
  echo "=== 有测试失败，失败详情： ==="
  grep -B2 -A8 '<failure>' "$RESULTS" | head -100
  exit 1
fi

if [ "$UNITY_EXIT" -ne 0 ]; then
  echo "Unity 退出码 $UNITY_EXIT，日志尾部："
  tail -40 "$LOGFILE"
  exit 2
fi

echo "EditMode 测试全部通过"
exit 0
```

```csharp
using System;

namespace EasyMoney.Core
{
    /// <summary>
    /// 金额值类型。内部一律用「分」为单位的 long 存储，杜绝浮点误差。
    /// </summary>
    public readonly struct Money : IEquatable<Money>, IComparable<Money>
    {
        public static readonly Money Zero = new Money(0);

        private readonly long m_Cents;

        private Money(long iCents)
        {
            m_Cents = iCents;
        }

        public long Cents => m_Cents;

        public static Money FromCents(long iCents)
        {
            return new Money(iCents);
        }

        public static Money FromYuan(decimal dYuan)
        {
            decimal dCents = dYuan * 100m;
            long iCents = (long)Math.Round(dCents, 0, MidpointRounding.AwayFromZero);
            return new Money(iCents);
        }

        public decimal ToYuan()
        {
            return m_Cents / 100m;
        }

        public static Money operator +(Money oLeft, Money oRight)
        {
            return new Money(oLeft.m_Cents + oRight.m_Cents);
        }

        public static Money operator -(Money oLeft, Money oRight)
        {
            return new Money(oLeft.m_Cents - oRight.m_Cents);
        }

        public static Money operator -(Money oValue)
        {
            return new Money(-oValue.m_Cents);
        }

        public static bool operator <(Money oLeft, Money oRight) => oLeft.m_Cents < oRight.m_Cents;

        public static bool operator >(Money oLeft, Money oRight) => oLeft.m_Cents > oRight.m_Cents;

        public static bool operator <=(Money oLeft, Money oRight) => oLeft.m_Cents <= oRight.m_Cents;

        public static bool operator >=(Money oLeft, Money oRight) => oLeft.m_Cents >= oRight.m_Cents;

        public bool Equals(Money oOther) => m_Cents == oOther.m_Cents;

        public override bool Equals(object oObj) => oObj is Money oOther && Equals(oOther);

        public override int GetHashCode() => m_Cents.GetHashCode();

        public int CompareTo(Money oOther) => m_Cents.CompareTo(oOther.m_Cents);

        public override string ToString() => ToYuan().ToString("0.00");
    }
}
```

- [ ] **Step 4: 实现 MoneyParser**

创建 `Assets/Scripts/Core/MoneyParser.cs`：

```csharp
using System.Globalization;

namespace EasyMoney.Core
{
    /// <summary>
    /// 把用户输入的字符串解析成 Money。只接受纯数字（可带负号与最多两位小数），
    /// 不接受千分位、科学计数法、货币符号——记账场景下这些几乎总是误输入。
    /// </summary>
    public static class MoneyParser
    {
        public static bool TryParseYuan(string sText, out Money oResult)
        {
            oResult = Money.Zero;

            if (string.IsNullOrWhiteSpace(sText))
            {
                return false;
            }

            string sTrimmed = sText.Trim();

            if (!decimal.TryParse(
                    sTrimmed,
                    NumberStyles.AllowLeadingSign | NumberStyles.AllowDecimalPoint,
                    CultureInfo.InvariantCulture,
                    out decimal dYuan))
            {
                return false;
            }

            if (dYuan != decimal.Round(dYuan, 2))
            {
                return false;
            }

            oResult = Money.FromYuan(dYuan);
```

```csharp
using System;

namespace EasyMoney.Core
{
    /// <summary>
    /// 时间工具。全项目统一用 Unix 毫秒（UTC）在数据库与各层之间传递时间，
    /// 只有展示和「按月/按日分组」时才转成本地时间。
    /// </summary>
    public static class TimeUtil
    {
        private static readonly DateTime EPOCH_UTC =
            new DateTime(1970, 1, 1, 0, 0, 0, DateTimeKind.Utc);

        public static long ToUnixMs(DateTime oLocalTime)
        {
            DateTime oUtc = oLocalTime.Kind == DateTimeKind.Utc
                ? oLocalTime
                : oLocalTime.ToUniversalTime();

            return (long)(oUtc - EPOCH_UTC).TotalMilliseconds;
        }

        public static DateTime FromUnixMs(long iUnixMs)
        {
            return EPOCH_UTC.AddMilliseconds(iUnixMs).ToLocalTime();
        }

        public static long StartOfDayMs(DateTime oLocalTime)
        {
            DateTime oDate = oLocalTime.Date;
            DateTime oWithKind = DateTime.SpecifyKind(oDate, DateTimeKind.Local);
            return ToUnixMs(oWithKind);
        }

        public static long StartOfMonthMs(int iYear, int iMonth)
        {
            DateTime oFirstDay = new DateTime(iYear, iMonth, 1, 0, 0, 0, DateTimeKind.Local);
            return ToUnixMs(oFirstDay);
        }

        public static long StartOfNextMonthMs(int iYear, int iMonth)
        {
            DateTime oFirstDay = new DateTime(iYear, iMonth, 1, 0, 0, 0, DateTimeKind.Local);
            return ToUnixMs(oFirstDay.AddMonths(1));
        }

        public static (int Year, int Month) CurrentYearMonth()
        {
            DateTime oNow = DateTime.Now;
            return (oNow.Year, oNow.Month);
        }
    }
}
```

注意 `StartOfDayMs` 里 `oLocalTime.Date` 返回的 `DateTime` 其 `Kind` 会被抹成 `Unspecified`，直接 `ToUniversalTime()` 会按本地时区猜——虽然结果通常正确，但 `SpecifyKind` 显式标定更安全，也避免将来有人改 `Kind` 语义时静默出错。

创建 `Assets/Scripts/Data/EasyMoneyDb.cs`：

```csharp
using SQLite;

namespace EasyMoney.Data
{
    /// <summary>
    /// 数据库连接与建表。传 ":memory:" 得到内存库（测试用），
    /// 传文件路径得到持久化库（运行时用 Application.persistentDataPath）。
    /// </summary>
    public sealed class EasyMoneyDb : System.IDisposable
    {
        public const int SCHEMA_VERSION = 1;

        private readonly string m_DbPath;
        private SQLiteConnection m_Connection;

        public EasyMoneyDb(string sDbPath)
        {
            m_DbPath = sDbPath;
        }

        public SQLiteConnection Connection
        {
            get
            {
                if (m_Connection == null)
                {
                    throw new System.InvalidOperationException("数据库尚未打开，请先调用 Open()");
                }
                return m_Connection;
            }
        }

        public void Open()
        {
            if (m_Connection != null)
            {
                return;
            }

            SQLitePCL.Batteries_V2.Init();

            m_Connection = new SQLiteConnection(m_DbPath, SQLiteOpenFlags.ReadWrite | SQLiteOpenFlags.Create);
            m_Connection.Execute("PRAGMA foreign_keys = ON;");
            m_Connection.Execute("PRAGMA journal_mode = WAL;");

            _createTables();
            _ensureSchemaVersion();
        }

        public void Close()
        {
            if (m_Connection == null)
            {
                return;
            }

            m_Connection.Close();
            m_Connection = null;
        }

        public void Dispose()
        {
            Close();
        }

        private void _createTables()
        {
            m_Connection.Execute(Schema.CREATE_SCHEMA_VERSION);
            m_Connection.Execute(Schema.CREATE_ACCOUNT);
            m_Connection.Execute(Schema.CREATE_CATEGORY);
            m_Connection.Execute(Schema.CREATE_TX);
            m_Connection.Execute(Schema.CREATE_INDEXES);
        }

        private void _ensureSchemaVersion()
        {
            int iCount = m_Connection.ExecuteScalar<int>("SELECT COUNT(*) FROM schema_version");
            if (iCount == 0)
            {
                m_Connection.Execute("INSERT INTO schema_version (version) VALUES (?)", SCHEMA_VERSION);
            }
        }
    }
}
```

> `PRAGMA journal_mode = WAL` 对 `:memory:` 库不生效但也不报错，可以安全保留。

```csharp
using System;
using System.Collections.Generic;
using EasyMoney.Core;
using SQLite;

namespace EasyMoney.Data
{
    public sealed class SqliteCategoryRepository : ICategoryRepository
    {
        private const string SELECT_COLUMNS = @"
            id         AS Id,
            name       AS Name,
            kind       AS Kind,
            parent_id  AS ParentId,
            icon_name  AS IconName,
            sort_order AS SortOrder,
            is_system  AS IsSystem";

        private readonly EasyMoneyDb m_Db;

        public SqliteCategoryRepository(EasyMoneyDb oDb)
        {
            m_Db = oDb;
        }

        public List<Category> GetAll()
        {
            return m_Db.Connection.Query<Category>(
                $"SELECT {SELECT_COLUMNS} FROM category ORDER BY kind, sort_order, id");
        }

        public List<Category> GetByKind(CategoryKind oKind)
        {
            return m_Db.Connection.Query<Category>(
                $"SELECT {SELECT_COLUMNS} FROM category WHERE kind = ? ORDER BY sort_order, id", (int)oKind);
        }

        public List<Category> GetChildren(int iParentId)
        {
            return m_Db.Connection.Query<Category>(
                $"SELECT {SELECT_COLUMNS} FROM category WHERE parent_id = ? ORDER BY sort_order, id", iParentId);
        }

        public Category GetById(int iId)
        {
            List<Category> lFound = m_Db.Connection.Query<Category>(
                $"SELECT {SELECT_COLUMNS} FROM category WHERE id = ? LIMIT 1", iId);

            return lFound.Count > 0 ? lFound[0] : null;
        }

        public int Insert(Category oCategory)
        {
            m_Db.Connection.Execute(
                @"INSERT INTO category (name, kind, parent_id, icon_name, sort_order, is_system)
                  VALUES (?, ?, ?, ?, ?, ?)",
                oCategory.Name,
                (int)oCategory.Kind,
                oCategory.ParentId,
                oCategory.IconName,
                oCategory.SortOrder,
                oCategory.IsSystem ? 1 : 0);

            oCategory.Id = m_Db.Connection.ExecuteScalar<int>("SELECT last_insert_rowid()");
            return oCategory.Id;
        }

        public void Update(Category oCategory)
        {
            m_Db.Connection.Execute(
                @"UPDATE category
                     SET name = ?, kind = ?, parent_id = ?, icon_name = ?, sort_order = ?, is_system = ?
                   WHERE id = ?",
                oCategory.Name,
                (int)oCategory.Kind,
                oCategory.ParentId,
                oCategory.IconName,
                oCategory.SortOrder,
                oCategory.IsSystem ? 1 : 0,
                oCategory.Id);
        }

        public bool Delete(int iId)
        {
            Category oCategory = GetById(iId);
            if (oCategory == null || oCategory.IsSystem)
            {
                return false;
            }

            if (GetChildren(iId).Count > 0)
            {
                return false;
            }

            m_Db.Connection.Execute("DELETE FROM category WHERE id = ?", iId);
            return true;
        }

        public int CountAll()
        {
            return m_Db.Connection.ExecuteScalar<int>("SELECT COUNT(*) FROM category");
        }
    }
}
```

```csharp
        private void _seedDefaultCategories()
        {
            int iCount = m_Connection.ExecuteScalar<int>("SELECT COUNT(*) FROM category");
            if (iCount > 0)
            {

            }

            foreach (Core.Category oCategory in DefaultCategories.Build())
            {

                    @"INSERT INTO category (name, kind, parent_id, icon_name, sort_order, is_system)
```

创建 `Assets/Scripts/Data/SqliteAccountRepository.cs`：

```csharp
using System.Collections.Generic;
using EasyMoney.Core;
using SQLite;

namespace EasyMoney.Data
{
    public sealed class SqliteAccountRepository : IAccountRepository
    {
        private const string SELECT_COLUMNS = @"
            id              AS Id,
            name            AS Name,
            type            AS Type,
            initial_balance AS InitialBalanceCents,
            is_archived     AS IsArchived,
            sort_order      AS SortOrder,
            created_at      AS CreatedAtMs";

        /// <summary>
        /// 余额 = 初始余额 + 收入 - 支出 - 转出 + 转入。
        /// 全部用相关子查询实时聚合，不做冗余存储。
        /// </summary>
        private const string SELECT_BALANCE_EXPRESSION = @"
            a.initial_balance
            + COALESCE((SELECT SUM(t.amount) FROM tx t WHERE t.account_id = a.id AND t.type = 1), 0)
            - COALESCE((SELECT SUM(t.amount) FROM tx t WHERE t.account_id = a.id AND t.type = 0), 0)
            - COALESCE((SELECT SUM(t.amount) FROM tx t WHERE t.account_id = a.id AND t.type = 2), 0)
            + COALESCE((SELECT SUM(t.amount) FROM tx t WHERE t.to_account_id = a.id AND t.type = 2), 0)";

        private readonly EasyMoneyDb m_Db;

        public SqliteAccountRepository(EasyMoneyDb oDb)
        {
            m_Db = oDb;
        }

        public List<Account> GetAll(bool bIncludeArchived = false)
        {
            string sWhere = bIncludeArchived ? string.Empty : "WHERE is_archived = 0";
            return m_Db.Connection.Query<Account>(
                $"SELECT {SELECT_COLUMNS} FROM account {sWhere} ORDER BY sort_order, id");
        }

        public List<AccountBalance> GetAllWithBalance(bool bIncludeArchived = false)
        {
            string sWhere = bIncludeArchived ? string.Empty : "WHERE a.is_archived = 0";

            List<AccountBalanceRow> lRows = m_Db.Connection.Query<AccountBalanceRow>(
                $@"SELECT {SELECT_COLUMNS},
                          {SELECT_BALANCE_EXPRESSION} AS BalanceCents
                     FROM account a
                     {sWhere}
                    ORDER BY a.sort_order, a.id");

            List<AccountBalance> lResult = new List<AccountBalance>();
            foreach (AccountBalanceRow oRow in lRows)
            {
                lResult.Add(new AccountBalance(oRow.ToAccount(), Money.FromCents(oRow.BalanceCents)));
            }

            return lResult;
        }

        public Account GetById(int iId)
        {
            List<Account> lFound = m_Db.Connection.Query<Account>(
                $"SELECT {SELECT_COLUMNS} FROM account WHERE id = ? LIMIT 1", iId);

            return lFound.Count > 0 ? lFound[0] : null;
        }

        public int Insert(Account oAccount)
        {
            m_Db.Connection.Execute(
                @"INSERT INTO account (name, type, initial_balance, is_archived, sort_order, created_at)
                  VALUES (?, ?, ?, ?, ?, ?)",
                oAccount.Name,
                (int)oAccount.Type,
                oAccount.InitialBalanceCents,
                oAccount.IsArchived ? 1 : 0,
                oAccount.SortOrder,
                oAccount.CreatedAtMs);

            oAccount.Id = m_Db.Connection.ExecuteScalar<int>("SELECT last_insert_rowid()");
            return oAccount.Id;
        }

        public void Update(Account oAccount)
        {
            m_Db.Connection.Execute(
                @"UPDATE account
                     SET name = ?, type = ?, initial_balance = ?, is_archived = ?, sort_order = ?, created_at = ?
                   WHERE id = ?",
                oAccount.Name,
                (int)oAccount.Type,
                oAccount.InitialBalanceCents,
                oAccount.IsArchived ? 1 : 0,
                oAccount.SortOrder,
                oAccount.CreatedAtMs,
                oAccount.Id);
        }

        public void SetArchived(int iId, bool bArchived)
        {
            m_Db.Connection.Execute(
                "UPDATE account SET is_archived = ? WHERE id = ?", bArchived ? 1 : 0, iId);
        }

        public bool Delete(int iId)
        {
            int iTxCount = m_Db.Connection.ExecuteScalar<int>(
                "SELECT COUNT(*) FROM tx WHERE account_id = ? OR to_account_id = ?", iId, iId);

            if (iTxCount > 0)
            {
                return false;
            }

            return m_Db.Connection.Execute("DELETE FROM account WHERE id = ?", iId) > 0;
        }

        public Money GetBalance(int iId)
        {
            long iCents = m_Db.Connection.ExecuteScalar<long>(
                $"SELECT {SELECT_BALANCE_EXPRESSION} FROM account a WHERE a.id = ?", iId);

            return Money.FromCents(iCents);
        }

        public Money GetTotalAssets()
        {
            long iCents = m_Db.Connection.ExecuteScalar<long>(
                $@"SELECT COALESCE(SUM({SELECT_BALANCE_EXPRESSION}), 0)
                     FROM account a
                    WHERE a.is_archived = 0");

            return Money.FromCents(iCents);
        }

        /// <summary>sqlite-net 的查询映射需要扁平结构，此内部类专门承接带余额的查询结果。</summary>
        private class AccountBalanceRow
        {
            public int Id { get; set; }
            public string Name { get; set; }
            public int Type { get; set; }
            public long InitialBalanceCents { get; set; }
            public int IsArchived { get; set; }
            public int SortOrder { get; set; }
            public long CreatedAtMs { get; set; }
            public long BalanceCents { get; set; }

            public Account ToAccount()
            {
                return new Account
                {
                    Id = Id,
                    Name = Name,
                    Type = (AccountType)Type,
                    InitialBalanceCents = InitialBalanceCents,
                    IsArchived = IsArchived != 0,
                    SortOrder = SortOrder,
                    CreatedAtMs = CreatedAtMs
                };
            }
        }
    }
}
```

> `is_archived` 在 `AccountBalanceRow` 里声明成 `int` 而非 `bool`，因为 SQLite 没有布尔类型，直接映射到 `bool` 在部分 sqlite-net 版本上会因 0/1 与 true/false 的转换差异抛异常。校验时用 `!= 0`。

```csharp
using System.Collections.Generic;

namespace EasyMoney.Core
{
    /// <summary>
    /// 记账规则校验。纯函数，不碰数据库——账户与分类列表由调用方查好传进来。
    /// </summary>
    public static class TransactionValidator
    {
        /// <summary>单笔上限 10 亿元，防止误输入一长串数字把统计冲垮。</summary>
        public const long MaxAmountCents = 100_000_000_000L;

        public static ValidationResult Validate(
            Transaction oTransaction,
            IList<Account> lAccounts,
            IList<Category> lCategories)
        {
            if (oTransaction == null)
            {
                return ValidationResult.Fail("账单数据为空");
            }

            if (oTransaction.AmountCents <= 0)
            {
                return ValidationResult.Fail("金额必须大于 0");
            }

            if (oTransaction.AmountCents > MaxAmountCents)
            {
                return ValidationResult.Fail("金额超出上限");
            }

            if (oTransaction.OccurredAtMs <= 0)
            {
                return ValidationResult.Fail("请选择账单时间");
            }

            ValidationResult oAccountResult = _validateAccounts(oTransaction, lAccounts);
            if (!oAccountResult.IsValid)
            {
                return oAccountResult;
            }

            if (oTransaction.Type == TxType.Transfer)
            {
                return ValidationResult.Ok();
            }

            return _validateCategory(oTransaction, lCategories);
        }

        private static ValidationResult _validateAccounts(Transaction oTransaction, IList<Account> lAccounts)
        {
            Account oAccount = _findAccount(lAccounts, oTransaction.AccountId);
            if (oAccount == null)
            {
                return ValidationResult.Fail("请选择账户");
            }

            if (oTransaction.Type != TxType.Transfer)
            {
                return ValidationResult.Ok();
            }

            if (oTransaction.ToAccountId == 0)
            {
                return ValidationResult.Fail("请选择转入账户");
            }

            if (oTransaction.ToAccountId == oTransaction.AccountId)
            {
                return ValidationResult.Fail("转出与转入不能是同一个账户");
            }

            if (_findAccount(lAccounts, oTransaction.ToAccountId) == null)
            {
                return ValidationResult.Fail("转入账户不存在");
            }

            return ValidationResult.Ok();
        }

        private static ValidationResult _validateCategory(Transaction oTransaction, IList<Category> lCategories)
        {
            if (oTransaction.CategoryId == 0)
            {
                return ValidationResult.Fail("请选择分类");
            }

            Category oCategory = _findCategory(lCategories, oTransaction.CategoryId);
            if (oCategory == null)
            {
                return ValidationResult.Fail("分类不存在");
            }

            CategoryKind oExpected = oTransaction.Type == TxType.Income
                ? CategoryKind.Income
                : CategoryKind.Expense;

            if (oCategory.Kind != oExpected)
            {
                return ValidationResult.Fail("分类与收支类型不匹配");
            }

            return ValidationResult.Ok();
        }

        private static Account _findAccount(IList<Account> lAccounts, int iId)
        {
            if (lAccounts == null)
            {
                return null;
            }

            foreach (Account oAccount in lAccounts)
            {
                if (oAccount.Id == iId)
                {
                    return oAccount;
                }
            }

            return null;
        }

        private static Category _findCategory(IList<Category> lCategories, int iId)
        {
            if (lCategories == null)
            {
                return null;
            }

            foreach (Category oCategory in lCategories)
            {
                if (oCategory.Id == iId)
                {
                    return oCategory;
                }
            }

            return null;
        }
    }
}
```

```csharp
using System.Collections.Generic;
using EasyMoney.Core;

namespace EasyMoney.Data
{
    /// <summary>
    /// 记账编排：查齐校验所需的账户与分类，跑校验，通过后落库并维护时间戳。
    /// 所有写账单的入口都应该走这里，不要直接调 ITransactionRepository。
    /// </summary>
    public sealed class TransactionService
    {
        private readonly ITransactionRepository m_TxRepo;
        private readonly IAccountRepository m_AccountRepo;
        private readonly ICategoryRepository m_CategoryRepo;

        public TransactionService(
            ITransactionRepository oTxRepo,
            IAccountRepository oAccountRepo,
            ICategoryRepository oCategoryRepo)
        {
            m_TxRepo = oTxRepo;
            m_AccountRepo = oAccountRepo;
            m_CategoryRepo = oCategoryRepo;
        }

        /// <summary>新建或更新一条账单。Id 为 0 视为新建。</summary>
        public ValidationResult Save(Transaction oTransaction, long iNowMs)
        {
            List<Account> lAccounts = m_AccountRepo.GetAll(bIncludeArchived: true);
            List<Category> lCategories = m_CategoryRepo.GetAll();

            ValidationResult oResult = TransactionValidator.Validate(oTransaction, lAccounts, lCategories);
            if (!oResult.IsValid)
            {
                return oResult;
            }

            bool bIsNew = oTransaction.Id == 0;

            if (bIsNew)
            {
                oTransaction.CreatedAtMs = iNowMs;
                oTransaction.UpdatedAtMs = iNowMs;
                m_TxRepo.Insert(oTransaction);
            }
            else
            {
                oTransaction.UpdatedAtMs = iNowMs;
                m_TxRepo.Update(oTransaction);
            }

            return ValidationResult.Ok();
        }

        /// <summary>
        /// 账户间转账。只写一条 tx 记录（type=Transfer，account_id=转出，to_account_id=转入），
        /// 因此天然原子，不存在「转出成功转入失败」的中间态。
        /// </summary>
        public ValidationResult CreateTransfer(
            int iFromAccountId,
            int iToAccountId,
            long iAmountCents,
            string sNote,
            long iOccurredAtMs,
            long iNowMs)
        {
            Transaction oTx = new Transaction
            {
                Type = TxType.Transfer,
                AmountCents = iAmountCents,
                AccountId = iFromAccountId,
                ToAccountId = iToAccountId,
                CategoryId = 0,
                Note = sNote ?? string.Empty,
                OccurredAtMs = iOccurredAtMs
            };

            return Save(oTx, iNowMs);
        }
    }
}
```

```csharp
        public List<Transaction> Query(TransactionQuery oQuery)
        {
            List<object> lArgs = new List<object>();
            string sWhere = _buildWhere(oQuery, lArgs);

            lArgs.Add(oQuery.Limit);
            lArgs.Add(oQuery.Offset);

            return m_Db.Connection.Query<Transaction>(
                $@"SELECT {SELECT_COLUMNS}
                     FROM tx
                     {sWhere}
                    ORDER BY occurred_at DESC, id DESC
                    LIMIT ? OFFSET ?",
                lArgs.ToArray());
        }

        public int Count(TransactionQuery oQuery)
        {
            List<object> lArgs = new List<object>();
            string sWhere = _buildWhere(oQuery, lArgs);

            return m_Db.Connection.ExecuteScalar<int>($"SELECT COUNT(*) FROM tx {sWhere}", lArgs.ToArray());
        }

        /// <summary>拼装 WHERE 子句。所有值都走参数占位符，不做字符串拼接。</summary>
        private static string _buildWhere(TransactionQuery oQuery, List<object> lArgs)
        {
            List<string> lClauses = new List<string>();

            if (oQuery.StartMs.HasValue)
            {
                lClauses.Add("occurred_at >= ?");
                lArgs.Add(oQuery.StartMs.Value);
            }

            if (oQuery.EndMs.HasValue)
            {
                lClauses.Add("occurred_at < ?");
                lArgs.Add(oQuery.EndMs.Value);
            }

            if (oQuery.Type.HasValue)
            {
                lClauses.Add("type = ?");
                lArgs.Add((int)oQuery.Type.Value);
            }

            if (oQuery.CategoryId.HasValue)
            {
                lClauses.Add("category_id = ?");
                lArgs.Add(oQuery.CategoryId.Value);
            }

            if (oQuery.AccountId.HasValue)
            {
                if (oQuery.AccountIncludesTransfers)
                {
                    lClauses.Add("(account_id = ? OR (type = 2 AND to_account_id = ?))");
                    lArgs.Add(oQuery.AccountId.Value);
                    lArgs.Add(oQuery.AccountId.Value);
                }
                else
                {
                    lClauses.Add("account_id = ?");
                    lArgs.Add(oQuery.AccountId.Value);
                }
            }

            if (oQuery.MinCents.HasValue)
            {
                lClauses.Add("amount >= ?");
                lArgs.Add(oQuery.MinCents.Value);
            }

            if (oQuery.MaxCents.HasValue)
            {
                lClauses.Add("amount <= ?");
                lArgs.Add(oQuery.MaxCents.Value);
            }

            if (!string.IsNullOrWhiteSpace(oQuery.Keyword))
            {
                // ESCAPE '\' 让用户输入的 % 和 _ 退化为普通字符，
                // 否则搜 "100%" 会把所有以 100 开头的备注都match出来。
                string sPattern = "%" + _escapeLike(oQuery.Keyword.Trim()) + "%";
                lClauses.Add(@"note LIKE ? ESCAPE '\'");
                lArgs.Add(sPattern);
            }

            if (lClauses.Count == 0)
            {
                return string.Empty;
            }

            return "WHERE " + string.Join(" AND ", lClauses);
        }

        private static string _escapeLike(string sText)
        {
            return sText
                .Replace(@"\", @"\\")
                .Replace("%", @"\%")
                .Replace("_", @"\_");
        }
```

> `Execute`/`Query`/`ExecuteScalar` 都接受 `params object[]`。传入 `lArgs.ToArray()` 时正好展开成参数数组。注意 SQLite-net 对参数顺序的匹配是**按出现顺序**的，所以 `_buildWhere` 里 `lArgs.Add` 的顺序必须与 `lClauses.Add` 严格一致——写新条件时务必成对添加。

```csharp
using System.Collections.Generic;

namespace EasyMoney.Core
{
    public static class ReportCalculator
    {
        public const string UNCATEGORIZED_NAME = "未分类";

        public static PeriodSummary BuildSummary(IEnumerable<Transaction> lTransactions)
        {
            PeriodSummary oSummary = new PeriodSummary();

            if (lTransactions == null)
            {
                return oSummary;
            }

            long iIncomeCents = 0;
            long iExpenseCents = 0;
            int iCount = 0;

            foreach (Transaction oTx in lTransactions)
            {
                if (oTx.Type == TxType.Transfer)
                {
                    continue;
                }

                if (oTx.Type == TxType.Income)
                {
                    iIncomeCents += oTx.AmountCents;
                }
                else
                {
                    iExpenseCents += oTx.AmountCents;
                }

                iCount++;
            }

            oSummary.Income = Money.FromCents(iIncomeCents);
            oSummary.Expense = Money.FromCents(iExpenseCents);
            oSummary.TxCount = iCount;

            return oSummary;
        }

        public static List<CategoryBreakdownItem> BuildBreakdown(
            IEnumerable<Transaction> lTransactions,
            TxType oType,
            IList<Category> lCategories)
        {
            Dictionary<int, CategoryBreakdownItem> dItems = new Dictionary<int, CategoryBreakdownItem>();

            if (lTransactions != null)
            {
                foreach (Transaction oTx in lTransactions)
                {
                    if (oTx.Type != oType || oTx.Type == TxType.Transfer)
                    {
                        continue;
                    }

                    if (!dItems.TryGetValue(oTx.CategoryId, out CategoryBreakdownItem oItem))
                    {
                        oItem = new CategoryBreakdownItem
                        {
                            CategoryId = oTx.CategoryId,
                            CategoryName = _resolveName(oTx.CategoryId, lCategories),
                            Total = Money.Zero,
                            TxCount = 0
                        };

                        dItems[oTx.CategoryId] = oItem;
                    }

                    oItem.Total = oItem.Total + Money.FromCents(oTx.AmountCents);
                    oItem.TxCount++;
                }
            }

            List<CategoryBreakdownItem> lResult = new List<CategoryBreakdownItem>(dItems.Values);
            lResult.Sort(_compareByTotalDescending);

            AssignRatios(lResult);

            return lResult;
        }

        public static void AssignRatios(List<CategoryBreakdownItem> lItems)
        {
            if (lItems == null || lItems.Count == 0)
            {
                return;
            }

            long iGrandTotalCents = 0;
            foreach (CategoryBreakdownItem oItem in lItems)
            {
                iGrandTotalCents += oItem.Total.Cents;
            }

            if (iGrandTotalCents <= 0)
            {
                foreach (CategoryBreakdownItem oItem in lItems)
                {
                    oItem.Ratio = 0m;
                }
                return;
            }

            foreach (CategoryBreakdownItem oItem in lItems)
            {
                oItem.Ratio = (decimal)oItem.Total.Cents / iGrandTotalCents;
            }
        }

        private static string _resolveName(int iCategoryId, IList<Category> lCategories)
        {
            if (lCategories != null)
            {
                foreach (Category oCategory in lCategories)
                {
                    if (oCategory.Id == iCategoryId)
                    {
                        return oCategory.Name;
                    }
                }
            }

            return UNCATEGORIZED_NAME;
        }

        private static int _compareByTotalDescending(CategoryBreakdownItem oLeft, CategoryBreakdownItem oRight)
        {
            int iCompare = oRight.Total.Cents.CompareTo(oLeft.Total.Cents);
            if (iCompare != 0)
            {
                return iCompare;
            }

            // 金额相同时按分类 Id 稳定排序，避免界面顺序在多次查询间抖动
            return oLeft.CategoryId.CompareTo(oRight.CategoryId);
        }
    }
}
```

```csharp
using System;
using EasyMoney.Core;
using EasyMoney.Data;

namespace EasyMoney.App
{
    /// <summary>
    /// 应用级依赖容器。持有数据库连接与全部仓储，界面层统一从这里取。
    /// 不依赖 UnityEngine，可以在 EditMode 测试里直接 new 出来跑。
    /// </summary>
    public sealed class AppContext : IDisposable
    {
        private static AppContext s_Instance;

        private EasyMoneyDb m_Db;
        private bool m_IsDisposed;

        public static AppContext Instance => s_Instance;

        public EasyMoneyDb Db => m_Db;

        public IAccountRepository Accounts { get; private set; }

        public ICategoryRepository Categories { get; private set; }

        public ITransactionRepository Transactions { get; private set; }

        public TransactionService TxService { get; private set; }

        /// <summary>任何写操作完成后触发，页面据此刷新自己。</summary>
        public event Action DataChanged;

        public void Initialize(string sDbPath)
        {
            m_Db = new EasyMoneyDb(sDbPath);
            m_Db.Open();

            Accounts = new SqliteAccountRepository(m_Db);
            Categories = new SqliteCategoryRepository(m_Db);
            Transactions = new SqliteTransactionRepository(m_Db);
            TxService = new TransactionService(Transactions, Accounts, Categories);

            s_Instance = this;
        }

        public void NotifyDataChanged()
        {
            DataChanged?.Invoke();
        }

        public void Dispose()
        {
            if (m_IsDisposed)
            {
                return;
            }

            m_IsDisposed = true;

            if (m_Db != null)
            {
                m_Db.Dispose();
                m_Db = null;
            }

            if (s_Instance == this)
            {
                s_Instance = null;
            }
        }
    }
}
```

```csharp
using UnityEngine;

namespace EasyMoney.App.UI
{
    /// <summary>
    /// 中文字体解析。UGUI 的 Text 用动态字体，运行时会向系统字体回退，
    /// 所以按平台列出常见中文字体名逐个尝试即可，不需要往包里塞字体文件。
    /// </summary>
    public static class FontProvider
    {
        private const int FONT_SIZE = 32;

        private static readonly string[] FONT_CANDIDATES =
        {
            "Microsoft YaHei",
            "微软雅黑",
            "Noto Sans CJK SC",
            "Source Han Sans CN",
            "Droid Sans Fallback",
            "PingFang SC",
            "Heiti SC",
            "SimHei",
            "Arial Unicode MS"
        };

        private static Font s_Cached;

        public static Font Resolve()
        {
            if (s_Cached != null)
            {
                return s_Cached;
            }

            foreach (string sName in FONT_CANDIDATES)
            {
                Font oFont = Font.CreateDynamicFontFromOSFont(sName, FONT_SIZE);
                if (oFont != null && oFont.dynamic)
                {
                    s_Cached = oFont;
                    return s_Cached;
                }
            }

            // 兜底：Unity 内置字体。Android 上它仍会向系统回退，中文一般能显示。
            s_Cached = Resources.GetBuiltinResource<Font>("LegacyRuntime.ttf");
            return s_Cached;
        }
    }
}
```

> `LegacyRuntime.ttf` 是 Unity 2022 起的名字，旧版叫 `Arial.ttf`。本项目固定 2022.3，用前者。

```csharp
using UnityEngine.Events;

namespace EasyMoney.App.UI

    /// <summary>
    /// 用代码搭 UGUI。所有界面都经由这里创建，好处是样式集中、
    /// 可以 diff、可以 review，不必手工拖拽 Prefab。
    /// </summary>
    public static class UiFactory
    {
        public static readonly Color COLOR_BACKGROUND = new Color(0.96f, 0.96f, 0.97f);
        public static readonly Color COLOR_CARD = Color.white;
        public static readonly Color COLOR_PRIMARY = new Color(0.20f, 0.55f, 0.90f);

        public static RectTransform CreateRect(Transform oParent, string sName)
        {

            RectTransform oRect = oGo.GetComponent<RectTransform>();
            oRect.SetParent(oParent, false);

            return oImage;

            Transform oParent, string sName, string sContent, int iFontSize,

            Text oText = oRect.gameObject.AddComponent<Text>();

            oText.horizontalOverflow = HorizontalWrapMode.Wrap;

            RectTransform oViewport = CreateRect(oBackground.transform, "Viewport");

            oViewport.gameObject.AddComponent<RectMask2D>();

            oLayout.childControlWidth = true;
            oLayout.childForceExpandHeight = false;
            oLayout.childForceExpandWidth = true;

            oLayout.padding = new RectOffset(16, 16, 8, 8);

            ContentSizeFitter oFitter = oContent.gameObject.AddComponent<ContentSizeFitter>();

            ScrollRect oScroll = oBackground.gameObject.AddComponent<ScrollRect>();
            oScroll.viewport = oViewport;
            oScroll.content = oContent;
            oScroll.horizontal = false;
            oScroll.vertical = true;
            oScroll.movementType = ScrollRect.MovementType.Elastic;
            oScroll.scrollSensitivity = 30f;

            return oScroll;

        /// <summary>创建一个带固定高度的横向行容器，常用于列表项。</summary>
        public static RectTransform CreateRow(Transform oParent, string sName, float fHeight)
        {
            Image oRow = CreatePanel(oParent, sName, COLOR_CARD);

            LayoutElement oElement = oRow.gameObject.AddComponent<LayoutElement>();

            oElement.preferredHeight = fHeight;
```

```csharp
using UnityEngine;

namespace EasyMoney.App.UI

    /// <summary>
    /// 页面基类。Root 铺满整个内容区，子类在 Root 下搭自己的界面。
    /// </summary>
    public abstract class PageBase : MonoBehaviour

        public abstract string Title { get; }

        public RectTransform Root => m_Root;

        /// <summary>由 PageRouter 在创建时调用。</summary>

        {
            m_Root = oRoot;
            _build();
        }

        /// <summary>页面被切换到时调用，子类在这里刷新数据。</summary>
        public virtual void OnShow()
        {
        }

        protected abstract void _build();
    }
}
```

创建 `Assets/Scripts/App/UI/PageRouter.cs`：

```csharp
using System;
using System.Collections.Generic;
using UnityEngine;

namespace EasyMoney.App.UI
{
    /// <summary>
    /// 页面路由。同一时刻只显示一个页面，切换时调用 OnShow 让页面刷新数据。
    /// </summary>
    public sealed class PageRouter
    {
        private readonly Dictionary<string, PageBase> m_Pages = new Dictionary<string, PageBase>();
        private string m_CurrentKey;

        public event Action<string> PageChanged;

        public string CurrentKey => m_CurrentKey;

        public void Register(string sKey, PageBase oPage)
        {
            m_Pages[sKey] = oPage;
        }

        public void Show(string sKey)
        {
            if (!m_Pages.TryGetValue(sKey, out PageBase oTarget))
            {
                Debug.LogError($"未注册的页面: {sKey}");
                return;
            }

            foreach (KeyValuePair<string, PageBase> oPair in m_Pages)
            {
                oPair.Value.Root.gameObject.SetActive(oPair.Key == sKey);
            }

            m_CurrentKey = sKey;
            oTarget.OnShow();
            PageChanged?.Invoke(sKey);
        }

        /// <summary>把当前页面重新走一遍 OnShow，用于数据变化后刷新。</summary>
        public void RefreshCurrent()
        {
            if (m_CurrentKey != null && m_Pages.TryGetValue(m_CurrentKey, out PageBase oPage))
            {
                oPage.OnShow();
            }
        }
    }
}
```

```csharp
using System.IO;
using EasyMoney.App.UI;
using UnityEngine;
using UnityEngine.EventSystems;
using UnityEngine.UI;

namespace EasyMoney.App
{
    /// <summary>
    /// 场景入口。挂在场景里唯一的空物体上，负责建库、搭界面骨架、装配路由。
    /// </summary>
    public sealed class AppRoot : MonoBehaviour
    {
        private static readonly (string Key, string Label)[] TABS =
        {
            ("record", "记一笔"),
            ("list", "账单"),
            ("account", "账户"),
            ("report", "报表")
        };

        private AppContext m_Context;
        private PageRouter m_Router;
        private RectTransform m_ContentArea;

        private void Awake()
        {
            Application.targetFrameRate = 60;

            m_Context = new AppContext();
            m_Context.Initialize(Path.Combine(Application.persistentDataPath, "easymoney.db"));

            _buildUi();
            _buildPages();

            m_Context.DataChanged += _onDataChanged;

            m_Router.Show("record");
        }

        private void OnDestroy()
        {
            if (m_Context != null)
            {
                m_Context.DataChanged -= _onDataChanged;
                m_Context.Dispose();
            }
        }

        private void _onDataChanged()
        {
            m_Router.RefreshCurrent();
        }

        private void _buildUi()
        {
            _ensureEventSystem();

            GameObject oCanvasGo = new GameObject("Canvas", typeof(RectTransform));
            Canvas oCanvas = oCanvasGo.AddComponent<Canvas>();
            oCanvas.renderMode = RenderMode.ScreenSpaceOverlay;

            CanvasScaler oScaler = oCanvasGo.AddComponent<CanvasScaler>();
            oScaler.uiScaleMode = CanvasScaler.ScaleMode.ScaleWithScreenSize;
            oScaler.referenceResolution = new Vector2(Theme.REF_WIDTH, Theme.REF_HEIGHT);
            oScaler.screenMatchMode = CanvasScaler.ScreenMatchMode.MatchWidthOrHeight;

            // 0 = 按宽度匹配。竖屏应用宽度恒定，高度随屏幕比例伸缩，
            // 这样在 18:9 / 20:9 的机器上内容不会被横向拉伸。
            oScaler.matchWidthOrHeight = 0f;

            oCanvasGo.AddComponent<GraphicRaycaster>();

            RectTransform oCanvasRect = oCanvasGo.GetComponent<RectTransform>();

            Image oBackground = UiFactory.CreatePanel(oCanvasRect, "Background", UiFactory.COLOR_BACKGROUND);
            UiFactory.Stretch(oBackground.rectTransform);

            m_ContentArea = UiFactory.CreateRect(oCanvasRect, "ContentArea");
            m_ContentArea.anchorMin = new Vector2(0, 0);
            m_ContentArea.anchorMax = new Vector2(1, 1);
            m_ContentArea.offsetMin = new Vector2(0, 140);
            m_ContentArea.offsetMax = Vector2.zero;

            Image oHeader = UiFactory.CreatePanel(oCanvasRect, "Header", UiFactory.COLOR_CARD);
            oHeader.rectTransform.anchorMin = new Vector2(0, 1);
            oHeader.rectTransform.anchorMax = new Vector2(1, 1);
            oHeader.rectTransform.pivot = new Vector2(0.5f, 1);
            oHeader.rectTransform.anchoredPosition = Vector2.zero;
            oHeader.rectTransform.sizeDelta = new Vector2(0, 110);

            Text oTitle = UiFactory.CreateText(oHeader.transform, "Title", "EasyMoney", 40,
                TextAnchor.MiddleCenter);
            UiFactory.Stretch(oTitle.rectTransform);

            _buildTabBar(oCanvasRect);
        }

        private void _buildTabBar(RectTransform oCanvasRect)
        {
            Image oTabBar = UiFactory.CreatePanel(oCanvasRect, "TabBar", UiFactory.COLOR_CARD);
            oTabBar.rectTransform.anchorMin = new Vector2(0, 0);
            oTabBar.rectTransform.anchorMax = new Vector2(1, 0);
            oTabBar.rectTransform.pivot = new Vector2(0.5f, 0);
            oTabBar.rectTransform.anchoredPosition = Vector2.zero;
            oTabBar.rectTransform.sizeDelta = new Vector2(0, 140);

            HorizontalLayoutGroup oLayout = oTabBar.gameObject.AddComponent<HorizontalLayoutGroup>();
            oLayout.childControlWidth = true;
            oLayout.childControlHeight = true;
            oLayout.childForceExpandWidth = true;
            oLayout.childForceExpandHeight = true;
            oLayout.padding = new RectOffset(8, 8, 8, 8);

            foreach ((string sKey, string sLabel) in TABS)
            {
                string sCapturedKey = sKey;
                UiFactory.CreateButton(oTabBar.transform, $"Tab_{sKey}", sLabel,
                    () => m_Router.Show(sCapturedKey),
                    UiFactory.COLOR_PRIMARY, 30);
            }
        }

        private void _buildPages()
        {
            m_Router = new PageRouter();

            _register("record", new Pages.RecordPage());
            _register("list", new Pages.TransactionListPage());
            _register("account", new Pages.AccountPage());
            _register("report", new Pages.ReportPage());

            m_Router.PageChanged += sKey => _updateHeader(sKey);
        }

        private void _register(string sKey, PageBase oPage)
        {
            RectTransform oRoot = UiFactory.CreateRect(m_ContentArea, $"Page_{sKey}");
            UiFactory.Stretch(oRoot);

            oPage.Attach(oRoot);
            m_Router.Register(sKey, oPage);
        }

        private void _updateHeader(string sKey)
```

```csharp
using System.Collections.Generic;

namespace EasyMoney.Core
{
    /// <summary>
    /// 生成记账页的快捷金额按钮。以「最近同类消费均值」为中心，
    /// 上下各铺一档，减少日常记账的输入量。
    /// </summary>
    public static class QuickAmountHelper
    {
        public const long FALLBACK_CENTS = 1000;   // 10 元

        private static readonly long[] FALLBACK_STEPS = { 1000, 3000, 5000, 10000 };

        public static List<Money> BuildQuickAmounts(long iRecentAverageCents)
        {
            List<Money> lResult = new List<Money>();

            if (iRecentAverageCents <= 0)
            {
                foreach (long iCents in FALLBACK_STEPS)
                {
                    lResult.Add(Money.FromCents(iCents));
                }

                return lResult;
            }

            long iBase = _roundToNiceNumber(iRecentAverageCents);

            lResult.Add(Money.FromCents(_clamp(iBase / 2)));
            lResult.Add(Money.FromCents(_clamp(iBase)));
            lResult.Add(Money.FromCents(_clamp(iBase * 2)));
            lResult.Add(Money.FromCents(_clamp(iBase * 4)));

            return lResult;
        }

        /// <summary>把金额对齐到 1/5/10/50/100 元这类「好记」的档位。</summary>
        private static long _roundToNiceNumber(long iCents)
        {
            long[] lSteps = { 100, 500, 1000, 2000, 5000, 10000, 20000, 50000, 100000 };

            foreach (long iStep in lSteps)
            {
                if (iCents <= iStep)
                {
                    return iStep;
                }
            }

            return 100000;
        }

        private static long _clamp(long iCents)
        {
            if (iCents < 1)
            {
                return 1;
            }

            if (iCents > TransactionValidator.MaxAmountCents)
            {
                return TransactionValidator.MaxAmountCents;
            }

            return iCents;
        }
    }
}
```

```csharp
        private void _refresh()
        {
            AppContext oContext = AppContext.Instance;

            m_MonthLabel.text = $"{m_Year}年{m_Month}月";

        private void _renderList(List<Transaction> lTransactions, AppContext oContext)
        {
            for (int i = m_ListContent.childCount - 1; i >= 0; i--)
            {
                UnityEngine.Object.Destroy(m_ListContent.GetChild(i).gameObject);

            {

                oElement.minHeight = 200f;
                oElement.preferredHeight = 200f;
                return;
            }

            Dictionary<int, string> dCategoryNames = _buildCategoryNameMap(oContext);
            Dictionary<int, string> dAccountNames = _buildAccountNameMap(oContext);

            string sLastDate = null;

            foreach (Transaction oTx in lTransactions)
            {
                string sDate = TimeUtil.FromUnixMs(oTx.OccurredAtMs).ToString("yyyy-MM-dd");
                if (sDate != sLastDate)
                {
                    _addDateHeader(sDate);
                    sLastDate = sDate;
                }

                _addTransactionRow(oTx, dCategoryNames, dAccountNames, oContext);
            }
        }

        private void _addDateHeader(string sDate)
        {
            RectTransform oRow = UiFactory.CreateRow(m_ListContent, $"Date_{sDate}", DATE_ROW_HEIGHT);

            Image oImage = oRow.GetComponent<Image>();
            if (oImage != null)
            {
                oImage.color = UiFactory.COLOR_BACKGROUND;

            Text oLabel = UiFactory.CreateText(oRow, "Label", _formatDate(sDate), 28,
                TextAnchor.MiddleLeft, UiFactory.COLOR_TEXT_WEAK);
            UiFactory.Stretch(oLabel.rectTransform);
        }

        private static string _formatDate(string sIsoDate)
        {
            if (DateTime.TryParse(sIsoDate, out DateTime oDate))
            {
                string[] lWeekdays = { "周日", "周一", "周二", "周三", "周四", "周五", "周六" };
                return $"{oDate.Month}月{oDate.Day}日 {lWeekdays[(int)oDate.DayOfWeek]}";
            }

            return sIsoDate;
        }

        private void _addTransactionRow(
            Transaction oTx,
            Dictionary<int, string> dCategoryNames,
            Dictionary<int, string> dAccountNames,
            AppContext oContext)
        {
            RectTransform oRow = UiFactory.CreateRow(m_ListContent, $"Tx_{oTx.Id}", TX_ROW_HEIGHT);

            string sCategory = oTx.IsTransfer
                ? "转账"
                : _lookup(dCategoryNames, oTx.CategoryId);

            VerticalLayoutGroup oRowLayout = oRow.GetComponent<VerticalLayoutGroup>();
            if (oRowLayout != null)
            {
                UnityEngine.Object.Destroy(oRowLayout);
            }

            RectTransform oLeft = UiFactory.CreateRect(oRow, "Left");
            LayoutElement oLeftElement = oLeft.gameObject.AddComponent<LayoutElement>();
            oLeftElement.flexibleWidth = 1f;

            VerticalLayoutGroup oLeftLayout = oLeft.gameObject.AddComponent<VerticalLayoutGroup>();
            oLeftLayout.childControlHeight = false;
            oLeftLayout.childControlWidth = true;
            oLeftLayout.childForceExpandHeight = false;
            oLeftLayout.childForceExpandWidth = true;

            string sNote = string.IsNullOrWhiteSpace(oTx.Note) ? sCategory : oTx.Note;
            Text oNoteText = UiFactory.CreateText(oLeft, "Note", sNote, 30, TextAnchor.LowerLeft);
            oNoteText.gameObject.AddComponent<LayoutElement>().preferredHeight = 60f;

            string sSubtitle = oTx.IsTransfer
                ? $"{_lookup(dAccountNames, oTx.AccountId)} → {_lookup(dAccountNames, oTx.ToAccountId)}"
                : $"{sCategory} · {_lookup(dAccountNames, oTx.AccountId)}";

            Text oSubtitleText = UiFactory.CreateText(oLeft, "Subtitle", sSubtitle, 24,
                TextAnchor.UpperLeft, UiFactory.COLOR_TEXT_WEAK);
            oSubtitleText.gameObject.AddComponent<LayoutElement>().preferredHeight = 50f;

            Text oAmount = UiFactory.CreateText(oRow, "Amount", _formatAmount(oTx), 32,
                TextAnchor.MiddleRight, _amountColor(oTx));
            UiFactory.SetPreferredWidth(oAmount.rectTransform, 260f);

            Button oDelete = UiFactory.CreateButton(oRow, "Delete", "删", () =>
            {
                oContext.Transactions.Delete(oTx.Id);
                oContext.NotifyDataChanged();
            }, UiFactory.COLOR_CARD, 26);
            UiFactory.SetPreferredWidth(oDelete.GetComponent<RectTransform>(), 90f);
            oDelete.GetComponentInChildren<Text>().color = UiFactory.COLOR_TEXT_WEAK;
        }

        private static string _formatAmount(Transaction oTx)
        {
            string sPrefix = oTx.Type switch
            {
                TxType.Income => "+",
                TxType.Expense => "-",
                _ => string.Empty
            };

            return sPrefix + Money.FromCents(oTx.AmountCents);
        }

        private static Color _amountColor(Transaction oTx)
        {
            return oTx.Type switch
            {
                TxType.Income => UiFactory.COLOR_INCOME,
                TxType.Expense => UiFactory.COLOR_EXPENSE,
                _ => UiFactory.COLOR_TEXT
            };
        }

        private static Dictionary<int, string> _buildCategoryNameMap(AppContext oContext)
        {
            Dictionary<int, string> dResult = new Dictionary<int, string>();
            foreach (Category oCategory in oContext.Categories.GetAll())
            {
                dResult[oCategory.Id] = oCategory.Name;
            }

            return dResult;
        }

        private static Dictionary<int, string> _buildAccountNameMap(AppContext oContext)
        {
            Dictionary<int, string> dResult = new Dictionary<int, string>();
            foreach (Account oAccount in oContext.Accounts.GetAll(bIncludeArchived: true))
            {
                dResult[oAccount.Id] = oAccount.Name;
            }

            return dResult;
        }

        private static string _lookup(Dictionary<int, string> dMap, int iKey)
        {
            return dMap.TryGetValue(iKey, out string sValue) ? sValue : "未分类";
        }
    }
```

```csharp
                    return;
                }

                UnityEngine.Object.Destroy(oOverlay.gameObject);
                oContext.NotifyDataChanged();

                    oContext.Accounts.SetArchived(oAccount.Id, true);
                    UnityEngine.Object.Destroy(oOverlay.gameObject);
                    oContext.NotifyDataChanged();
                }, UiFactory.COLOR_EXPENSE, 30);
            }

        private bool _tryApply(
            Account oAccount, string sName, string sBalanceText, bool bIsNew,
            Text oMessage, AppContext oContext)
        {
            string sTrimmedName = (sName ?? string.Empty).Trim();
            if (string.IsNullOrEmpty(sTrimmedName))
            {
                oMessage.text = "请填写账户名称";
                return false;
            }

            long iBalanceCents = 0;
            if (!string.IsNullOrWhiteSpace(sBalanceText))
            {
                if (!MoneyParser.TryParseYuan(sBalanceText, out Money oBalance))
                {
                    oMessage.text = "初始余额格式不正确";
                    return false;
                }

                iBalanceCents = oBalance.Cents;
            }

            oAccount.Name = sTrimmedName;
            oAccount.InitialBalanceCents = iBalanceCents;

            if (bIsNew)
            {
                oAccount.CreatedAtMs = TimeUtil.ToUnixMs(System.DateTime.Now);
                oContext.Accounts.Insert(oAccount);
            }
            else
            {
                oContext.Accounts.Update(oAccount);
            }

            return true;
        }

        private RectTransform oContextRoot()
        {
            return Root;
        }
    }
```

```bash
PROJECT_PATH="E:/Projects/easymoney"
UNITY_EXE="${UNITY_EXE:-D:/unity/unity2022/2022.3.53f1c1/Editor/Unity.exe}"
```

创建 `Assets/Scripts/App/Editor/BuildScript.cs`：

```csharp
using System.IO;
using UnityEditor;
using UnityEditor.Build.Reporting;
using UnityEngine;

namespace EasyMoney.App.EditorTools
{
    /// <summary>
    /// 命令行构建入口。用法：
    /// Unity.exe -quit -batchmode -projectPath &lt;path&gt; -buildTarget Android
    ///           -executeMethod BuildScript.BuildAndroid
    /// </summary>
    public static class BuildScript
    {
        private const string OUTPUT_PATH = "Builds/EasyMoney.apk";

        [MenuItem("EasyMoney/构建 Android APK")]
        public static void BuildAndroid()
        {
            string sOutputPath = Path.Combine(
                Directory.GetParent(Application.dataPath).FullName, OUTPUT_PATH);

            Directory.CreateDirectory(Path.GetDirectoryName(sOutputPath));

            BuildPlayerOptions oOptions = new BuildPlayerOptions
            {
                scenes = new[] { "Assets/Scenes/SampleScene.unity" },
                locationPathName = sOutputPath,
                target = BuildTarget.Android,
                options = BuildOptions.None
            };

            BuildReport oReport = BuildPipeline.BuildPlayer(oOptions);
            BuildSummary oSummary = oReport.summary;

            if (oSummary.result == BuildResult.Succeeded)
            {
                Debug.Log($"构建成功: {sOutputPath}，大小 {oSummary.totalSize / 1024 / 1024} MB");
                EditorApplication.Exit(0);
                return;
            }

            Debug.LogError($"构建失败: {oSummary.result}，错误 {oSummary.totalErrors} 个");
            EditorApplication.Exit(1);
        }
    }
}
```

## 后续路线图

MVP 完成后，清单里还剩 7 个模块。按「用户价值 ÷ 实现成本」排序如下，**每一期都应该是能独立交付、独立验收的**。

### 第二期：让记账更省事

| 模块 | 关键设计要点 | 主要落点 |
|---|---|---|
| **标签系统** | 新增 `tag` 与 `tx_tag` 两张表（多对多）；数据库需升到 SCHEMA_VERSION=2 并写迁移逻辑 | Data 层新增 `ITagRepository`，`TransactionQuery` 加 `TagIds` 维度 |
| **搜索筛选增强** | 二级分类下钻、保存常用筛选条件 | `TransactionQuery.IncludeChildCategories`，新增 `saved_filter` 表 |
| **分类管理** | 自定义分类的增删改、图标选择、拖拽排序 | 复用 Task 15 的弹窗模式，`category` 表已有 `parent_id`/`icon_name` 字段 |
| **工具功能** | 计算器、还款计算器、费率计算器都是纯函数 | Core 层新增 `Tools/` 目录，全部可走 TDD |

### 第三期：提醒与自动化

| 模块 | 关键设计要点 | 主要落点 |
|---|---|---|
| **提醒功能** | Android 侧需要 `NotificationManager` + `AlarmManager`；用 Unity 的 `AndroidJavaObject` 调；需要 `POST_NOTIFICATIONS` 权限（Android 13+） | 新增 `EasyMoney.Notifications` 层；提醒规则表 |
| **重复账单** | 定期账单模板（房租、订阅），到期前提醒 | 新增 `recurring_rule` 表 + 应用启动时的补记检查 |
| **批量导入** | 支付宝/微信账单 CSV 解析 + 去重 | Core 层 CSV 解析器（纯函数好测），Data 层批量插入走事务 |
| **OCR 拍照记账** | 需要接第三方 OCR（百度/腾讯云）或本地模型；**这一项成本远超其余所有项，建议单独评估** | 新增 Python 服务或 Android 原生插件 |

### 第四期：数据与共享（Python 后端在此登场）

| 模块 | 关键设计要点 |
|---|---|
| **数据备份恢复** | 最简做法：把 SQLite 文件导出为下载目录；进阶：加密备份包 |
| **数据导出 Excel/PDF** | Excel 可用 EPPlus/NPOI 类库；PDF 在 Unity 里较麻烦，建议生成 HTML 再打印 |
| **数据同步 / 家庭共享 / 多人记账 / 权限管理** | **这是 Python 后端的启动点。** 需要：用户体系、鉴权、冲突解决策略（建议按 `updated_at` 做 last-write-wins + 墓碑删除）、增量同步协议。这是整个清单里工程量最大的一块，值得单独立项 |
| **AI 建议 / 智能分类** | 依赖前三期的数据积累；智能分类可以先做本地规则（备注关键词 → 分类），再考虑模型 |

### 不建议做的

- **数据同步之前的「历史数据归档」**：本地 App 的数据量几年也到不了需要归档的规模，属于伪需求。
- **多币种 / 汇率转换**：除非确实有外币消费，否则引入币种维度会让 `Money` 类型和所有统计 SQL 复杂化，收益极低。
